# Cornerfen 1.0 TEST
Native Java/Canvas Android 8+ Scrin-style rectangle corner-loop puzzle.

Shade tiles so every edge-connected dark block is a filled rectangle. Each rectangle has at most one numbered clue, and that number gives its area. Clue tiles stay dark. Rectangles without clues are allowed. Each rectangle touches exactly two other rectangles at corners, and all rectangles form one closed chain. Rectangles cannot share edges. Tap blank tiles to shade or restore. Twelve unique 4x4 clue boards have twelve distinct completed shadings.

Saved corner palette and shade marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java set-components, pairwise rectangle-fill and neighbor-graph oracle checks all 65536 masks per board against production bounding boxes and bitset graph connectivity, confirming one solution each. Fixed clues, bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Registry803, 90 recovered READMEs and recent cumulative stage/release records found no Scrin match. Shared rectangular-component and corner-contact backbone with Ivoryfen Mochikoro is disclosed. Ivoryfen uses a connected light rectangle network, exactly one clue per rectangle and no dark 2x2; this uses dark rectangles in a single degree-two corner cycle, allows unclued rectangles and has no background 2x2 rule. Unlike Blockbloom Chocona, there are no outlined room shade quotas; the corner-cycle graph constrains the blocks. Known Scrin genre, not a global invention. Full prior local corpus was lost; no ALL-local scan claimed. Rules https://maybepuzzles.com/2019/04/17/puzzle-173-scrin-and-release-pzprjs-v0-11-0/ and https://morassgames.com/games/scrin/ .
